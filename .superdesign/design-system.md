# Spotify Quiz visual system

The product is a personal Spotify listening quiz. Use a near-black base, neon-lime interaction accent, high-contrast warm-white type, and subtle album-art-inspired color fields. The mood should feel like a late-night music app: energetic, tactile, and editorial rather than a generic dashboard.

Use Space Grotesk for display/body type and DM Mono for metadata labels. Preserve accessible contrast, clear focus states, and a responsive single-column mobile layout. Prefer artwork-derived gradients and restrained glass/blur effects over excessive decoration.
